# Module-1-L1
The Arduino LED Monitoring System uses an Arduino Uno, LED, resistor, and breadboard to demonstrate digital output control. It also features a Streamlit dashboard that displays the LED's ON and OFF status.


Components and Connections:

1. Arduino Uno – serves as the main controller.
2. Breadboard – holds and connects the electronic components.
3. LED – serves as the light indicator.
4. 220Ω Resistor – limits the current to protect the LED.
5. Jumper Wires – connect the components.
6. Digital Pin 8 – connected to the resistor and LED's positive leg.
7. LED's Negative Leg – connected to the breadboard's negative rail.
8. GND – connected to the blue negative rail.

What Happened During Testing:

The LED blinked every second, turning ON and OFF through the Arduino program. The Streamlit dashboard also displayed the LED's ON and OFF status.
